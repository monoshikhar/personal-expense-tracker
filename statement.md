# Project Statement

## Problem
It can be difficult to remember small daily expenses and know how much money has been spent in a month.

## Aim
Make a simple program to record expenses and show basic spending totals.

## Scope
The program runs in a terminal. It stores expenses on the same computer in JSON files. It is intended for one person and does not connect to a bank account.

## Target users
Students or anyone who wants to keep a simple record of personal spending.

## Main features
- Add, view, edit and delete an expense
- Search by category
- Show total and category-wise spending
- Set a monthly budget and check spending
- Export the list to CSV
